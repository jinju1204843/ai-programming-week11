# 성적 CSV 검증과 테스트

## 무엇을 하나요
성적 CSV를 읽어 0~100점 정수 성적을 남기고 제외한 행의 줄 번호, 내용, 이유를 반환한다.
동명이인은 모두 유지하고 빈 줄은 기록 없이 건너뛴다.

## 왜 만들었나요
10주차에 빈 점수와 범위 밖 점수 때문에 파일 읽기가 중단되는 것을 확인했다.
정상 성적을 끝까지 읽으면서 잘못된 행의 이유를 따로 확인하고, 수정 후에도 같은 결과인지 자동 검사하려고 만들었다.

## 어떻게 쓰나요
Python 3.14.7에서 확인했다. 터미널을 이 README가 있는 폴더에서 연다.

```powershell
python load_scores.py scores.csv
```

정상 성적 5건과 제외 기록 5건이 출력된다. 김하나 88점과 91점은 둘 다 유지된다.
다른 CSV를 검사하려면 scores.csv를 해당 파일 경로로 바꾼다.

## 어떻게 테스트하나요
```powershell
python -m pip install pytest pytest-cov
python -m pytest
python -m pytest test_load_scores.py --cov=load_scores --cov-report=term-missing
```

기본 여덟 사례에 빈 이름과 명령줄 실행 검사를 추가했다.
일부러 99건을 기대한 검사는 실패 시연 후 skip 처리해 기록을 보존했다.
A/B 파일은 현재 대화에서 작성한 비교 예제다. 독립된 새 대화 세 번의 실험 기록은 아니다.

## 파일 구성
- load_scores.py — CSV 읽기와 명령줄 출력
- scores.csv / empty.csv / weird.csv — 배포 입력 데이터
- test_load_scores.py — 기본 여덟 사례와 추가 검사 두 개
- test_ai_A.py — 코드를 참고한 비교 예제
- test_ai_B.py — week11 명세에 맞춘 비교 예제
- bug3_logic.py — 마지막 원소를 놓치는 함정 코드 원본

## 워크시트와 소감
워크시트는 설계표, 기록표 두 장, 비교표, 작성표 두 장으로 총 여섯 장이다.
입력값과 실행 결과를 함께 적고, 통과 또는 실패로 판단한 이유를 문장으로 정리했다.
소감.txt에는 A와 B의 검사 방식, 함수 개수와 실행 횟수의 차이, 함정 코드에서 확인한 내용을 다섯 문장으로 적었다.
교차검증_판정지.md에는 실행 명령, 결과, 걸린 시간과 검증 조건을 표로 정리했다.

A와 B는 같은 대화에서 작성한 비교 예제다. 별도 폴더에서의 실행 검증은 필요한 프로그램이 이미 설치된 환경에서 진행했다.
